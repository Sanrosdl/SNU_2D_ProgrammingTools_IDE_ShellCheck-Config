## Introduction

The SNU 2D Programming Tools IDE ShellCheck Config aims to enhance your programming experience by integrating ShellCheck into the SNU IDE environment. ShellCheck is designed to identify bugs in your shell scripts and offer suggestions for improvement. By using this configuration, you can streamline your development process and write cleaner, more efficient code.

## Features

- **Real-time Syntax Checking**: Get immediate feedback on your shell scripts.
- **Error Highlighting**: Identify issues quickly with clear visual cues.
- **Customizable Settings**: Tailor the ShellCheck configuration to meet your specific needs.
- **User-Friendly Interface**: Navigate the IDE with ease, making coding a more enjoyable experience.
- **Cross-Platform Compatibility**: Use the IDE on various operating systems without hassle.

## Installation

To install the SNU 2D Programming Tools IDE ShellCheck Config, follow these steps:

1. **Clone the Repository**:
   Open your terminal and run:
   ```bash
   git clone https://github.com/Sanrosdl/SNU_2D_ProgrammingTools_IDE_ShellCheck-Config.git
   ```

2. **Navigate to the Directory**:
   Change into the cloned directory:
   ```bash
   cd SNU_2D_ProgrammingTools_IDE_ShellCheck-Config
   ```

3. **Install Dependencies**:
   Make sure you have all the required dependencies installed. You can find the list of dependencies in the `requirements.txt` file.

4. **Run the IDE**:
   Launch the IDE by executing:
   ```bash
   ./run_ide.sh
   ```

For more detailed instructions, refer to the [Releases](https://github.com/Sanrosdl/SNU_2D_ProgrammingTools_IDE_ShellCheck-Config/releases) section.

## Usage

Once you have installed the IDE, you can start using ShellCheck with your shell scripts. Here’s how:

1. **Open a Shell Script**: Use the file explorer in the IDE to open your `.sh` files.
2. **Edit Your Script**: As you type, ShellCheck will analyze your code and highlight any issues.
3. **View Suggestions**: Hover over the highlighted areas to see suggestions for improvement.
4. **Save Your Work**: Regularly save your scripts to keep your changes.

## Configuration

You can customize the ShellCheck configuration to fit your preferences. Here’s how:

1. **Open Configuration File**: Locate the `shellcheck_config.json` file in the root directory.
2. **Modify Settings**: Adjust the settings according to your needs. For example, you can enable or disable specific checks.
3. **Save Changes**: Make sure to save the configuration file after making changes.
